Skill · Claude Code

"Levo guarda-chuva?" merece um sim ou não — não uma tabela.

Skill que consulta o tempo de qualquer cidade do mundo via Open-Meteo, sem API key, e responde com a decisão na frente.

Começar o guia Ver no GitHub
O que é

Previsão do tempo que responde a pergunta certa

A maior parte das perguntas sobre tempo não é sobre tempo — é sobre uma decisão que depende dele. A skill trata a previsão como insumo, não como produto.

🎯 Decisão na frente

Pergunta fechada ganha resposta fechada. "Leva sim — a chance bate 65% entre 15h e 18h." Os números vêm depois, e só os que importam pra aquela pergunta.

🔓 Sem API key

Usa a Open-Meteo: pública, gratuita, cobertura mundial, previsão de até 16 dias. Nada de cadastro, chave no .env ou cota estourando no meio do mês.

📊 Modo lote

Comparar lugares é uma requisição só — as 27 capitais do Brasil, ou qualquer lista de cidades, já ordenadas da mais quente pra mais fria.

Como funciona

Da frase solta ao número certo

Você não chama comando nenhum: fala normalmente e a skill dispara. O trabalho chato — achar a cidade, traduzir os 28 códigos WMO, formatar em PT-BR — já vem pronto no script bundlado, então o Claude gasta o esforço em interpretar o que você quis saber.

Você pergunta em PT-BR→ Geocoding da cidade→ Open-Meteo→ Recorte do que importa→ Decisão + 2-3 números

🗺️ Acha a cidade sozinho

Nome em português, com ou sem acento, Brasil ou exterior. Se não existir, ele avisa em vez de chutar outra parecida.

🕐 Escolhe o recorte

Pergunta de horário puxa o hora a hora; pergunta de fim de semana puxa os dias; pergunta de comparação puxa o lote.

⚠️ Mostra a ambiguidade

Homônimas grandes o bastante pra confundir (Springfield tem quatro) aparecem no aviso. Vilarejo irrelevante, não — seria só ruído.

Pré-requisitos

Node 18 e mais nada

Sem dependências, sem npm install, sem chave de API, sem serviço no ar. O script usa o fetch nativo do Node.

Claude Code

O CLI da Anthropic, que carrega skills da pasta ~/.claude/skills/.

claude --version

Node 18+

Precisa do fetch global, que entrou no Node 18.

Internet

Guia de uso · passo a passo

Instalar e perguntar

Três passos até a primeira resposta. O resto é conversa normal.

1

Clone e instale a skill

A pasta vai inteira pra ~/.claude/skills/, com o SKILL.md dentro.

git clone https://github.com/inematds/clima
cp -r clima ~/.claude/skills/clima
2

Confirme que registrou

No Claude Code, liste as skills disponíveis.

/skills   # clima deve aparecer na lista
3

Pergunte em linguagem natural

Você não precisa dizer "consulte o clima" — a skill dispara também nas perguntas indiretas, que são a maioria.

# direta
como tá o tempo em Floripa?

# decisão
posso gravar externa amanhã de manhã?
levo guarda-chuva hoje?

# comparação
temperatura das capitais agora
4

Ou rode o script direto

Útil quando você quer os dados crus pra outra coisa — o --json devolve tudo estruturado.

node ~/.claude/skills/clima/scripts/clima.mjs "Porto Alegre"
node ~/.claude/skills/clima/scripts/clima.mjs "São Paulo" --horas
node ~/.claude/skills/clima/scripts/clima.mjs --lote capitais
node ~/.claude/skills/clima/scripts/clima.mjs --lote "Recife,Natal,Salvador"

Todas as opções

🎯 O que a skill faz com esses dados

Os números acima viram resposta. Repare que nenhuma delas começa pela tabela.

# "levo guarda-chuva hoje?"
Leva sim. A chance de chuva em Porto Alegre bate 65% entre 15h e 18h —
de manhã tá seco, mas se você voltar de tarde pega. Máxima de 21°C.

# "posso gravar externa amanhã de manhã?"
Dá, e a manhã é a melhor janela. Entre 8h e 11h fica nublado sem chuva
(4-5%), 15-19°C, vento fraco de 5-6 km/h — nada que atrapalhe áudio.
Depois das 12h entra garoa e o vento sobe, então fecha antes do meio-dia.
Roadmap

Onde está e pra onde vai

A skill nasceu de uma conversa e cresceu por uso: o modo lote só existe porque a pergunta "temperatura das capitais" expôs que faltava.

Feito
Consulta de uma cidadeAgora, N dias (até 16), hora a hora e dia específico. Geocoding mundial em português, 28 códigos WMO traduzidos com emoji, saída em °C / % / mm / km/h.
Feito
Modo loteAtalho capitais com as 27 já georreferenciadas (uma requisição, sem 27 geocodings) ou lista livre de cidades. Ordena por temperatura e calcula a amplitude.
Feito
Desambiguação honestaHomônimas relevantes viram aviso (Springfield tem quatro nos EUA); irrelevantes são filtradas por população. No lote o rótulo mostra estado ou país — porque "Nova York" casa com Nova Iorque/Maranhão, que existe.
Próximo
Avaliação com casos de testeO evals/evals.json tem quatro casos escritos com critérios; falta rodar o loop comparando com e sem a skill pra medir se o "decisão na frente" pega de verdade.
Ideia
Qualidade do ar e índice UVA Open-Meteo tem endpoint de qualidade do ar e de UV. Encaixaria nas perguntas de saúde e de exposição ao sol, que hoje ficam de fora.
